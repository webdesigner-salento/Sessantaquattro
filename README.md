# Sessantaquattro Due

Due deck DJ nel browser che mandano l'audio ai canali di un mixer fisico.
EQ, crossfader, cue e cuffie restano sul mixer.

## Uso
1. Apri la pagina in Chrome o Edge (servono per scegliere l'uscita audio).
2. Collega il mixer al computer e premi **AVVIA AUDIO**.
3. Premi **SCEGLI USCITA** e seleziona il mixer.
4. Scegli la modalità (4 uscite, 2 uscite mono, stereo) e prova ogni deck con **TEST**.
5. Carica i brani con **CARICA** o trascinandoli su un deck.

## Note
- Il pitch cambia velocità e tono insieme (nessun key lock).
- Il controllo con il vinile e le funzioni interne di Serato non sono collegabili da un browser: la pagina manda solo audio.

Pagina unica, senza dipendenze da installare. Per pubblicarla con GitHub Pages: Settings → Pages → branch `main`, cartella `/ (root)`.
